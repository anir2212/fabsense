# Dashboard and insight query IDs

| ID | Inputs | SQL source and meaning |
|---|---|---|
| `flagged_excess_by_rows_v1` | Validated list of integer row IDs | `sum(greatest(observed - predicted, 0))` from `fact_meter_readings` for the IDs named in each insight. `verify_insights` checks every row and total. |
| `top_building_excess_v1` | One allowed meter name | Group flagged readings by building and sum positive observed-minus-baseline excess. The top row and its source IDs are cited. |
| `building_meter_excess_v1` | `Bnn` building ID and allowed meter name | Count flagged hours and sum positive excess for that building/meter. The result contains source IDs. |
| `meter_series_by_building_v1` | `Bnn` and allowed meter name | Select `hour_index, observed, predicted, flagged, row_id` ordered by hour for the Streamlit plot. The dashboard uses bound parameters and shows flagged row IDs. |

Numbers generated by the photo-bay or MSA modules come from their saved JSON/CSV outputs, not a language model. The local question router accepts only the named templates in `fabstack/agent.py`; it does not execute user-supplied SQL.
